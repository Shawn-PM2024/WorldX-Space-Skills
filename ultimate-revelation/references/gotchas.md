# Gotchas

这些模式来自长材料总结中的实际失败。只把新的、可复现的失败追加到这里，不让主流程无限增长。

| 失败模式 | 可观察症状 | 修正方式 |
|---|---|---|
| 结构正确但输出膨胀 | 每条都机械展开五个长段，结论被脚手架淹没 | 遵守用户长度；普通任务把推导和边界各压成一句，原则与行动按条件出现 |
| 用目录替代认知 | 标题是“AI、产品、组织”之类名词 | 改成可反驳判断，并说明它改变了什么理解 |
| 只有定位没有证据 | “见 12:08”“第 4 页”后直接给结论 | 展示最小充分原话、数字、事件或对比，定位放在其后 |
| 把重复当独立证据 | 同一说话人反复强调某观点，被编号成 F1–F4 | 去重为一条材料陈述；寻找独立观察、对比或反例 |
| 被醒目数字劫持 | 标题直接写“效率提高 60 倍”，正文才提口径有问题 | 先标为材料主张，把估算口径和自我否定放进同一证据簇 |
| 把案例外推成规律 | 一个家庭、公司或产品案例生成普遍结论 | 降级为可能性；没有第二类证据时明确样本边界 |
| 边界变成万能免责声明 | 每条都只写“样本有限，仍需验证” | 写出会让结论失效的具体条件、干扰变量或反例 |
| 强造第一性原理 | “价值来自信任”“一切都是选择”等口号无法生成原事实 | 停在洞察层；需要外部前提时标为候选原则并列前提 |
| 分块总结冒充全文结论 | 前几个章节的主题主导结果，后文反例消失 | 完成全局去重和聚类后再排名；披露未覆盖范围 |
| 多来源串线 | A 的数字被写成 B 的论据，或两个来源的相似观点被称为互证 | 每条证据保留来源；先判断口径与前提是否兼容 |
| OCR 猜词成为支点 | 不确定的人名、术语或数字出现在核心结论中 | 回看原页或音频；无法确认就换用不依赖该词的证据 |
| 把外部常识偷渡进材料 | 推导链出现材料从未提供的因果前提 | 单独标注并核验外部事实，或缩小结论到材料可支持范围 |

## 高风险信号

看到以下信号时，暂停写结论并回到证据账本：

- “显然”“必然”“已经证明”，但材料只有个人判断；
- 精确倍率、百分比或市场规模没有口径；
- 结论比所有原话都更确定；
- 每条认知都恰好有相同数量的证据；
- 所有观点被整理得没有冲突；
- 删除人物、数字和案例后，结论仍像通用励志句。
